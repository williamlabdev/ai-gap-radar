## What (2-3 sentences)

Portable engineering workflow skills picked from Matt Pocock's own `.agents` directory. Drop-in skills for Claude Code, Cursor, Codex-style coding agents covering real build/test/review loops.

## Why it blew up

- Distribution path: educator brand (TypeScript community) + copy-paste install + daily GitHub Trending presence.
- Data point: +11.8k stars in a single week (June 2026), +33.9k across August — #2 AI repo that month.
- Timing: rode the skills-explosion wave where every coding agent suddenly consumed `SKILL.md`; users shifted from "any skill" to "skills by authors I trust."

## License & risk

MIT, low license risk. Risk is quality variance across skills and no built-in security review — which is exactly the governance gap.

## Gap (what it leaves open — the part that matters for this repo)

No lint, no sandbox trial run, no permission manifest, no score. Enterprises want to adopt these skills but have no trust gate. See `opportunities/skill-security-linter.md`.
